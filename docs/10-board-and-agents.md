# 10 — Shared decision board

GitHub Project: **"Orca Demo — Feature Board"**
https://github.com/users/<owner>/projects/1

- Owner: `<owner>` · linked repo: `<owner>/<repo>`
- Fields: built-in **Status** (Todo / In Progress / Done) plus custom **Owner** and **Worktree**.
- Use it for feature and decision control: one card per feature, assign an Owner, move
  through Status. Agent work should reference the card and set `Worktree`.
- Seed items: "Feature: example (owner: Avi)", "Decision: shared-file change policy".

Teammates with access to the repo/project can view and edit live; it is the shared
"control over features and decisions" surface that the Orca shared runtime doesn't provide.
